# Examples

Apps generated by the semii CLI and committed as is (apart from a
`replace` directive pointing at this repository). Each is its own Go
module.

| Example | Database | Auth | Resources |
|---------|----------|------|-----------|
| [shop-postgres](shop-postgres) | Postgres | jwt, apikey | customers, products (unique SKU, decimal price), orders (ref to customer, soft delete) |
| [notes-mongo](notes-mongo) | MongoDB | session | notes (nullable text and JSON) |

They were created with:

```sh
semii new shop-postgres --db postgres --auth jwt,apikey
semii g resource Customer name:string:min=2 email:string:unique
semii g resource Product name:string sku:string:unique:max=32 price:decimal:min=0 stock:int:min=0:default=0
semii g resource Order customer:ref:Customer status:string:max=20:default=pending:index total:decimal:min=0 notes:text:null --soft-delete

semii new notes-mongo --db mongo --auth session
semii g resource Note title:string:min=1:max=200 body:text:null pinned:bool:default=false tags:json:null
```

Run one:

```sh
cd examples/shop-postgres
cp .env.example .env
docker compose up --build      # app on :8080 with its database
go test ./...                  # starts database containers for the tests
```
