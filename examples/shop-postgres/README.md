# shop-postgres

Go API generated by [semii](github.com/AhmadRaza-Khan/semii) v0.3.0-dev. All code here is yours.

## Run locally

```sh
cp .env.example .env
docker compose up -d db
semii migrate up
semii dev
```

## Common tasks

| Task | Command |
|------|---------|
| Add a resource | `semii g resource Order customer:ref:Customer total:decimal:min=0` |
| Add a migration | `semii g migration add_index` |
| List routes | `semii routes` |
| Run tests | `make test` (needs the database and `TEST_DATABASE_URL`) |
| Check setup | `semii doctor` |

## Layout

- `cmd/api` — entrypoint
- `internal/app` — explicit wiring and route registration
- `internal/<resource>` — model, service, repository, handler per resource
- `db/migrations` — goose migrations (embedded in the binary)
- `db/queries` — SQL compiled by sqlc into `db/sqlc`
