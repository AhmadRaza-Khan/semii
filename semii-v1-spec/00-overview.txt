SEMII v1 SPECIFICATION
00 - OVERVIEW
======================================================================

1. PITCH
--------
semii is a Rails-speed scaffolding framework for Go backend APIs. It
generates idiomatic, stdlib-based Go code that the developer owns
outright.

Thesis: the framework writes boring Go so you don't have to. Conventions
are delivered through CODE GENERATION, never through runtime magic.

2. DESIGN PRINCIPLES
--------------------
P1  Stdlib first. net/http, http.ServeMux (Go 1.22+ patterns),
    context.Context, log/slog, database/sql. No router dependency.
P2  Generated code is owned code. After generation it is plain Go in
    the user's repo; semii never re-reads or rewrites it at runtime.
P3  No hidden magic. No reflection-driven routing, no decorators, no
    struct-tag routing, no init()-time registration, no global state.
P4  No DI container. Wiring is explicit constructor calls in app.go.
P5  Every package is usable standalone. A user can import only
    semii/auth or semii/web without the CLI or other packages.
P6  Explicit errors. Handlers return error; semii maps it to HTTP.
P7  Secure by default. Deny-by-default routing, safe cookies, short
    token lifetimes, no hand-written crypto.
P8  API only. No templating, asset pipeline or frontend concerns.

3. v1 SCOPE
-----------
  01-cli.txt                CLI and generators
  02-project-layout.txt     Generated app layout and framework repo layout
  03-web.txt                Router, middleware, JSON, errors, pagination
  04-config.txt             Typed config loading
  05-data.txt               Databases, repos, migrations, transactions, seeds
  06-auth.txt               Authentication, policies, generated auth flows
  07-validation.txt         Validation and field error format
  08-testkit.txt            Testing toolkit, test DBs, factories, fakes
  09-ops.txt                Server lifecycle, health, logging, deploy files
  10-release-criteria.txt   Milestones and v1.0 release bar

4. v1 NON-GOALS (deferred to v2)
--------------------------------
Background jobs, full mailer package, cache, file storage, outbound and
inbound webhooks, OpenAPI generation, SDK generation, WebSockets/SSE,
OIDC, RBAC tables, multi-tenancy, audit log, OpenTelemetry, Prometheus,
distributed rate limiting, generated admin, LDAP/SAML/WebAuthn,
`semii upgrade`, i18n.

5. PERMANENTLY OUT
------------------
- Its own ORM (sqlc / official drivers; users may bring GORM or ent)
- A DI container
- Decorators, annotations, struct-tag routing
- Templating, views, asset pipeline
- Package-level singletons (no global DB, App, Logger)

6. REQUIREMENTS
---------------
- Go: supports the two latest stable Go releases (minimum 1.24 at launch)
- Module path: github.com/semii/semii (placeholder, final TBD)
- CLI binary: semii
- License: MIT (TBD)

7. SPEC CONVENTIONS
-------------------
MUST / SHOULD / MAY carry their RFC 2119 meaning.
Defaults are listed explicitly; every default is overridable via config
or constructor options unless marked FIXED.
