SEMII v1 SPECIFICATION
01 - CLI AND GENERATORS
======================================================================

1. GENERAL
----------
Binary: semii
Install: go install github.com/semii/semii/cmd/semii@latest

Global flags:
  --dry-run     Print files that would be created/changed; write nothing
  --force       Overwrite existing files (default: refuse and exit 1)
  --verbose     Debug output
  --no-color

Exit codes:
  0  success
  1  user error (bad args, file exists, invalid project)
  2  external tool failure (sqlc, go, goose)
  3  internal error

Project detection: commands other than `new`, `version`, `doctor` MUST
run inside a semii project (directory tree containing .semii.yaml).

Generator rules (all generators):
  G1  Output is gofmt'd and goimports'd.
  G2  Never silently overwrite a file. Conflict -> exit 1 listing files.
  G3  Edits to existing files (routes.go, app.go) happen only between
      marker comments:  // semii:routes:start  ...  // semii:routes:end
      If markers are missing, print the snippet to add manually.
  G4  Generated files start with:
      // Code generated by semii vX.Y.Z. You own this file; edit freely.
      (NOT the "DO NOT EDIT" header; that is reserved for sqlc output.)
  G5  Templates are embedded in the binary (embed.FS), selected by the
      db and auth settings in .semii.yaml.

2. COMMANDS
-----------

2.1 semii new <name>
  Flags:
    --module <path>     Go module path (default: <name>)
    --db <kind>         postgres | mysql | sqlite | mongo  (default postgres)
    --auth <list>       comma list of session,jwt,apikey or none
                        (default jwt)
    --id <kind>         uuid | bigint  (default uuid, v7). Mongo: ObjectID
    --no-docker         Skip Dockerfile and docker-compose.yml
    --no-ci             Skip .github/workflows
    --no-git            Skip git init
  Behaviour:
    - Creates layout from 02-project-layout.txt
    - Writes .semii.yaml (framework version, template version, db, auth, id)
    - Runs: go mod tidy, sqlc generate (SQL dbs), git init
    - If --auth != none, runs `semii generate auth` internally
    - Prints next steps (cp .env.example .env, docker compose up -d db,
      semii migrate up, semii dev)

2.2 semii generate resource <Name> [field:type[:modifier...]...]
  Alias: semii g resource
  Name: singular PascalCase (Order). Table/collection: snake plural
  (orders). Route base: /orders. Package: internal/order.

  Field types:
    string    VARCHAR(255) / string
    text      TEXT / string
    int       INTEGER / int32
    int64     BIGINT / int64
    bool      BOOLEAN / bool
    float     DOUBLE PRECISION / float64
    decimal   NUMERIC(18,4) / decimal.Decimal (shopspring)
    time      TIMESTAMPTZ / time.Time
    date      DATE / time.Time (date-only JSON "2006-01-02")
    uuid      UUID / uuid.UUID
    json      JSONB (MySQL JSON, SQLite TEXT) / json.RawMessage
    ref:<R>   FK to R's table, ON DELETE RESTRICT, indexed / R's id type

  Modifiers:
    null        nullable; Go type becomes pointer; JSON omits when nil
    unique      unique index
    index       plain index
    default=X   column default
    min=N max=N validation rules (length for strings, value for numbers)

  Always added: id, created_at, updated_at.
  Flag --soft-delete adds deleted_at and filters it in list/get queries.
  Flag --no-auth makes routes Public() (default: Require(auth.Authenticated())).
  Flag --only=model,repo,service,handler,migration,tests to limit output.

  Generates (SQL dbs):
    internal/<pkg>/model.go           struct + JSON tags
    internal/<pkg>/dto.go             CreateInput, UpdateInput (patch, ptr
                                      fields), ListFilter, with validate tags
    internal/<pkg>/repo.go            Repository interface
    internal/<pkg>/repo_sql.go        implementation over sqlc queries
    internal/<pkg>/service.go         business layer, takes Repository
    internal/<pkg>/handler.go         HTTP handlers
    internal/<pkg>/routes.go          func Register(r *web.Router, h *Handler)
    internal/<pkg>/fake_repo.go       in-memory Repository for unit tests
    internal/<pkg>/service_test.go    unit tests against fake repo
    internal/<pkg>/handler_test.go    integration tests via testkit
    internal/factory/<pkg>.go         test factory
    db/queries/<table>.sql            sqlc queries
    db/migrations/<ts>_create_<table>.sql
  Mongo replaces repo_sql.go with repo_mongo.go, skips queries and
  migration, and appends index setup to db/mongo/indexes.go.
  Modifies (between markers): internal/app/app.go, internal/app/routes.go
  Then runs: sqlc generate (SQL), go build ./... as a sanity check.

  Endpoints generated:
    GET    /orders          list (cursor pagination, filters on indexed fields)
    POST   /orders          create  -> 201 + Location header
    GET    /orders/{id}     get     -> 404 problem if missing
    PATCH  /orders/{id}     partial update
    DELETE /orders/{id}     -> 204

2.3 semii generate migration <name>
  SQL only. Creates db/migrations/<YYYYMMDDHHMMSS>_<name>.sql with goose
  -- +goose Up / -- +goose Down sections. Mongo: exit 1 with hint.

2.4 semii generate middleware <name>
  Creates internal/middleware/<name>.go with
  func <Name>(next http.Handler) http.Handler skeleton and a test.

2.5 semii generate auth
  Generates auth flows for strategies in .semii.yaml (see 06-auth.txt).
  Re-runnable with --strategy to add a strategy later.

2.6 semii dev
  - Builds ./cmd/api and runs it with SEMII_ENV=development
  - Watches **/*.go, db/queries/*.sql, .env (fsnotify, built in, no air)
  - On .sql change: sqlc generate, then rebuild
  - Debounce 200ms; kills old process with SIGTERM, then SIGKILL after 5s
  - Build errors printed; previous process kept running

2.7 semii routes
  Builds the app router without starting the server (calls
  app.Routes() exposed by generated code) and prints:
    METHOD  PATH            POLICY                 HANDLER
    GET     /orders         authenticated          order.(*Handler).List
    POST    /auth/login     public                 auth.(*Handler).Login
  Exit 1 if any route has no policy (same check as boot).
  --json for machine output.

2.8 semii migrate up|down|status|redo|create <name>
  Wraps goose (library, not binary). Reads DATABASE_URL from config.
  down rolls back one step; --to=<version> supported for up/down.
  Mongo: `migrate up` ensures indexes from db/mongo/indexes.go; others no-op.

2.9 semii db seed
  Runs db/seeds/seed.go (func Seed(ctx, deps) error). Refuses in
  production unless --allow-production.

2.10 semii doctor
  Checks: Go version, sqlc installed (SQL projects), .semii.yaml valid,
  required env vars present, DB reachable, migrations up to date.
  Prints PASS/WARN/FAIL per check.

2.11 semii version
  Prints CLI version, Go version, project template version if inside one.

3. .semii.yaml
--------------
  semii: 1.0.0          # framework version that created the project
  template: 1           # template schema version (used by v2 upgrade)
  module: github.com/acme/shop
  db: postgres
  auth: [jwt]
  id: uuid
