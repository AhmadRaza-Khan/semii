SEMII v1 SPECIFICATION
05 - DATA (packages db/*)
======================================================================

1. POSITION
-----------
semii does NOT abstract databases. The database is a GENERATOR CHOICE.
The swap point is the per-resource Repository interface. Services depend
on the interface; only repo_*.go knows the driver.

Supported in v1:
  postgres  pgx/v5 + pgxpool + sqlc
  mysql     database/sql + go-sql-driver/mysql + sqlc
  sqlite    database/sql + modernc.org/sqlite (pure Go, CGO_ENABLED=0) + sqlc
  mongo     mongo-go-driver v2

2. GENERATED REPOSITORY CONTRACT
--------------------------------
  type Repository interface {
      Create(ctx context.Context, in CreateInput) (Order, error)
      Get(ctx context.Context, id uuid.UUID) (Order, error)
      List(ctx context.Context, f ListFilter, p web.CursorParams) ([]Order, *string, error)
      Update(ctx context.Context, id uuid.UUID, in UpdateInput) (Order, error)
      Delete(ctx context.Context, id uuid.UUID) error
  }
Implementations MUST return:
  db.ErrNotFound   when no row/document matches
  db.ErrConflict   on unique-constraint / duplicate-key violations
  db.ErrForeignKey on FK violations (mapped to 409 by default)
Errors are wrapped: fmt.Errorf("order repo get: %w", err).

3. SHARED PACKAGE db
--------------------
  var ErrNotFound, ErrConflict, ErrForeignKey error
  type Tx interface (marker only; drivers expose concrete types)

4. DRIVER PACKAGES
------------------
4.1 db/pgxdb
  func Open(ctx context.Context, url string, o Options) (*pgxpool.Pool, error)
    Options: MaxConns (default 4*GOMAXPROCS), MinConns 0,
    MaxConnLifetime 1h, MaxConnIdleTime 30m, PingOnOpen true.
  func WithTx(ctx context.Context, pool *pgxpool.Pool, fn func(pgx.Tx) error, opts ...pgx.TxOptions) error
    Commit on nil error; rollback on error or panic (panic re-raised).
  func MapError(err error) error
    pgx.ErrNoRows->ErrNotFound, 23505->ErrConflict, 23503->ErrForeignKey

4.2 db/sqldb
  func Open(ctx context.Context, driver, dsn string, o Options) (*sql.DB, error)
  func WithTx(ctx context.Context, db *sql.DB, fn func(*sql.Tx) error, opts *sql.TxOptions) error
  func MapError(err error) error
    sql.ErrNoRows->ErrNotFound; MySQL 1062->ErrConflict, 1451/1452->ErrForeignKey;
    SQLite UNIQUE->ErrConflict, FOREIGN KEY->ErrForeignKey
  SQLite opens with: _pragma=foreign_keys(1), journal_mode(WAL),
  busy_timeout(5000).

4.3 db/mongodb
  func Open(ctx context.Context, uri, database string, o Options) (*mongo.Client, *mongo.Database, error)
  func WithTx(ctx context.Context, c *mongo.Client, fn func(ctx context.Context) error) error
    Requires replica set; returns a descriptive error on standalone.
    docker-compose for mongo starts a single-node replica set.
  func MapError(err error) error
    mongo.ErrNoDocuments->ErrNotFound, duplicate key (11000)->ErrConflict

5. SQL REPOS AND sqlc
---------------------
- sqlc.yaml generated per engine, output db/sqlc, package sqlc.
- Type overrides: uuid->github.com/google/uuid.UUID,
  numeric->github.com/shopspring/decimal.Decimal, jsonb->json.RawMessage,
  timestamptz->time.Time.
- Generated queries per resource: Create<R>, Get<R>, List<R> (keyset),
  Update<R> (COALESCE-based partial update via sqlc.narg),
  Delete<R>, Count<R>.
- Repos accept a DBTX (sqlc interface) so the same repo works inside a
  transaction: repo.WithTx(tx) returns a tx-bound copy.

6. IDS AND TIMESTAMPS
---------------------
- uuid (default): UUIDv7 generated in Go (uuid.NewV7) for sortable keys.
- bigint: database identity / AUTO_INCREMENT.
- mongo: primitive ObjectID, exposed in JSON as hex string.
- created_at/updated_at set in Go (UTC) at create/update, not by triggers.
- Soft delete: deleted_at nullable; generated queries filter
  deleted_at IS NULL; Delete sets it instead of DELETE.

7. MIGRATIONS (db/migrate)
--------------------------
- Wraps pressly/goose v3 as a library with embedded SQL files:
    //go:embed migrations/*.sql   (in db/embed.go of the generated app)
- func Up(ctx, db *sql.DB, fsys fs.FS) error, Down, Status, To(version)
- Timestamped versions (no sequential renumbering).
- Postgres migrations run with a session advisory lock to prevent
  concurrent runners.
- Apps do NOT auto-migrate on boot by default. Opt-in config
  DB_AUTO_MIGRATE=true (forbidden in production unless
  DB_AUTO_MIGRATE_PRODUCTION=true).
- Mongo: indexes declared in db/mongo/indexes.go as
  []mongo.IndexModel per collection; `semii migrate up` ensures them.

8. SEEDS
--------
db/seeds/seed.go:
  func Seed(ctx context.Context, d Deps) error
Run by `semii db seed`; seeds must be idempotent (upsert by natural key).
Generated seed creates an admin user when auth is enabled
(credentials from SEED_ADMIN_EMAIL / SEED_ADMIN_PASSWORD).
