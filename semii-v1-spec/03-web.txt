SEMII v1 SPECIFICATION
03 - HTTP (package web)
======================================================================

1. ROUTER
---------
Built on http.ServeMux. semii adds groups, error-returning handlers and
per-route policy metadata. Nothing else.

  type HandlerFunc func(w http.ResponseWriter, r *http.Request) error
  type Middleware  func(http.Handler) http.Handler

  func NewRouter(opts Options) *Router
  func (r *Router) Group(prefix string, mw ...Middleware) *Router
  func (r *Router) Handle(pattern string, h http.Handler) *Route
  func (r *Router) HandleFunc(pattern string, h HandlerFunc) *Route
  func (r *Router) Mount(prefix string, h http.Handler) *Route
  func (r *Router) Public() *Router                    // group default
  func (r *Router) Require(p ...auth.Policy) *Router   // group default
  func (r *Router) ServeHTTP(w http.ResponseWriter, req *http.Request)
  func (r *Router) Routes() []RouteInfo                // for `semii routes`
  func (r *Router) Verify() error                      // deny-by-default

  func (rt *Route) Public() *Route
  func (rt *Route) Require(p ...auth.Policy) *Route
  func (rt *Route) Name(n string) *Route

Pattern rules:
  - Patterns use ServeMux syntax: "GET /orders/{id}", "POST /orders".
  - Group prefix is spliced after the method:
      g := r.Group("/v1/orders"); g.HandleFunc("GET /{id}", h)
      => "GET /v1/orders/{id}"
  - Path params: r.PathValue("id") (stdlib). Helper:
      web.PathUUID(r, "id") (uuid.UUID, error)  -> 400 on bad format
      web.PathInt64(r, "id") (int64, error)
  - Method-less patterns are allowed but Verify() warns in dev.
  - 404 and 405 are rendered as problem+json (not stdlib plain text).

Policy resolution: route policy > nearest group policy > none.
Verify() returns an error listing every route with no policy.

2. HANDLER ERRORS
-----------------
HandlerFunc errors are passed to the router's ErrorHandler:
  - *web.Error            rendered as-is
  - validate.Errors       422 with field errors (07-validation.txt)
  - registered mapping    see 2.1
  - context.DeadlineExceeded -> 504; context.Canceled -> nothing written
  - anything else         500, generic detail, full error logged with
                          request_id

If the handler already wrote a response before returning an error, the
error is logged only.

  type Error struct {
      Status int
      Code   string       // machine code, snake_case
      Title  string       // defaults to http.StatusText(Status)
      Detail string
      Fields []FieldError
      Err    error        // wrapped cause, never serialized
  }
  func (e *Error) Error() string
  func (e *Error) Unwrap() error

  Constructors: web.BadRequest(detail), web.Unauthorized(detail),
  web.Forbidden(detail), web.NotFound(detail), web.Conflict(detail),
  web.Unprocessable(detail, fields...), web.TooManyRequests(retryAfter)

2.1 Domain error mapping
  func (r *Router) MapError(target error, status int, code string)
  Matching uses errors.Is in registration order.
  Defaults registered by NewRouter:
    db.ErrNotFound          404 not_found
    db.ErrConflict          409 conflict
    auth.ErrUnauthenticated 401 unauthenticated
    auth.ErrForbidden       403 forbidden
    auth.ErrInvalidCredentials 401 invalid_credentials

3. PROBLEM+JSON (RFC 9457)
--------------------------
Content-Type: application/problem+json
  {
    "type": "about:blank",
    "title": "Unprocessable Entity",
    "status": 422,
    "detail": "request validation failed",
    "code": "validation_failed",
    "request_id": "01JB...",
    "errors": [ {"field": "email", "code": "email", "message": "must be a valid email"} ]
  }
"errors" is omitted when empty. 500 detail is always
"internal server error" in production; dev includes err.Error().

4. JSON HELPERS
---------------
  func Decode[T any](r *http.Request) (T, error)
    - Requires Content-Type application/json (415 otherwise)
    - DisallowUnknownFields (400 unknown_field)
    - Rejects trailing data after the JSON value (400)
    - Body over limit -> 413
    - Runs validate.Struct on the result (422 on failure)
  func DecodeQuery[T any](r *http.Request) (T, error)
    - Binds query params via `query:"name"` tags; supports string, ints,
      bool, time (RFC3339), uuid, slices (repeated keys); validates
  func JSON(w http.ResponseWriter, status int, v any) error
  func Created(w http.ResponseWriter, location string, v any) error
  func NoContent(w http.ResponseWriter) error

  Encoding: encoding/json, no HTML escaping, trailing newline.

5. PAGINATION
-------------
Cursor (default for generated list endpoints):
  Query: ?limit=20&cursor=<opaque>
  limit default 20, max 100 (400 if exceeded or < 1)
  Cursor = base64url(JSON {"k": [<sort key values>], "d": "next"})
  Keyset on (created_at, id) descending by default.
  Response:
    { "data": [...], "next_cursor": "..." | null }

  type CursorParams struct { Limit int; Cursor *Cursor }
  func ParseCursor(r *http.Request, defLimit, maxLimit int) (CursorParams, error)
  func EncodeCursor(keys ...any) string
  type CursorPage[T any] struct { Data []T `json:"data"`; NextCursor *string `json:"next_cursor"` }

Offset (opt-in helper):
  Query: ?page=1&per_page=20 (max 100)
  Response: { "data": [...], "page": 1, "per_page": 20, "total": 134 }

6. BUILT-IN MIDDLEWARE
----------------------
Default order (outermost first) as generated in app.go:

  RequestID()
    Accept incoming X-Request-ID if 1-64 chars of [A-Za-z0-9._-],
    else generate ULID. Set in context and response header.
    web.RequestIDFrom(ctx) string

  RealIP(trusted []netip.Prefix)
    Uses X-Forwarded-For / X-Real-IP ONLY when the direct peer is in
    trusted. Default trusted: none. web.ClientIP(r) netip.Addr

  Logger(log *slog.Logger)
    One line per request at completion: request_id, method, route
    (pattern, not raw path), status, duration_ms, bytes_out, client_ip,
    principal_id. 5xx -> Error, 4xx -> Warn, else Info.
    Skips /healthz and /readyz.

  Recover(log *slog.Logger)
    Recovers panics, logs stack, writes 500 problem if nothing written.
    Re-panics http.ErrAbortHandler.

  SecurityHeaders(env string)
    X-Content-Type-Options: nosniff
    X-Frame-Options: DENY
    Referrer-Policy: no-referrer
    Content-Security-Policy: default-src 'none'; frame-ancestors 'none'
    Strict-Transport-Security: max-age=63072000; includeSubDomains
      (production only)

  CORS(cfg CORSConfig)
    Disabled when AllowedOrigins empty (default).
    Exact origin match; "*" not allowed together with AllowCredentials
    (startup error). Handles preflight with 204. Vary: Origin.
    Defaults: methods GET,POST,PUT,PATCH,DELETE; headers
    Authorization,Content-Type,X-Request-ID,X-API-Key; max-age 600.

  BodyLimit(n int64)
    http.MaxBytesReader. Default 1 MiB. Per-route override via
    route-level middleware.

  Timeout(d time.Duration)
    Sets context deadline (default 30s). Does NOT use
    http.TimeoutHandler (no buffering). Handlers must respect ctx.

  Gzip()
    Compresses when Accept-Encoding has gzip, response >= 1 KiB,
    content type is JSON/text, and no Content-Encoding is already set.
    Skips text/event-stream.

  Chain(h http.Handler, mw ...Middleware) http.Handler
    mw[0] is outermost.

7. RESPONSE WRITER
------------------
Internal wrapper records status and bytes, and preserves
http.Flusher, http.Hijacker and Unwrap() so http.ResponseController works.
